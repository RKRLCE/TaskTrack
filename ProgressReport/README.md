# TaskTrack: An Assignment Tracker App

A web app for students to organize assignments and deadlines. Helps manage multiple subjects by tracking due dates, sending reminders, and preventing late submissions through better time management.

---

## Overview

Many students struggle with keeping track of multiple assignments and deadlines across different subjects. This often leads to:

- **Late submissions** caused by poor task tracking.
- **Missed opportunities** to improve grades when assignments are forgotten.
- **Increased stress** due to disorganization and poor time management.

**TaskTrack** was created to address these problems by providing a **simple, accessible, and organized platform** where students can input assignments, manage deadlines, update tasks, and receive reminders.

---

## Planned Features

The **TaskTrack** app will include the following features:

1. **Add and Manage Assignments**  
   - Students can input:
     - Subject name  
     - Task description  
     - Due date  
     - Priority level (Low, Medium, High)

2. **Edit and Update Assignments**  
   - Users can modify assignment details such as:
     - Subject
     - Task description
     - Due date
     - Priority

3. **Delete Assignments**  
   - Users can remove completed or unnecessary tasks.
   - A confirmation message helps prevent accidental deletion.

4. **Assignment Status Tracking**  
   - Assignments can be marked as:
     - Pending
     - Completed
   - Completed tasks can be hidden or shown separately.

5. **Automatic Deadline Sorting**  
   - Tasks are automatically sorted by due date.
   - Assignments with the nearest deadlines appear first.

6. **Deadline and Overdue Reminders**  
   - Notifications alert users when assignments are due within a set number of days.
   - Overdue tasks are clearly labeled with how many days late they are.

7. **Subject Filtering and Search**  
   - Users can view assignments by subject.
   - Search allows users to quickly find tasks using keywords.

8. **Local Storage for Data**  
   - Assignments are saved directly on the device.
   - Data remains available after refreshing or closing the app.

9. **User-Friendly Design**  
   - Clean and minimal layout.
   - Simple navigation designed for students.

## Planned Inputs and Outputs

### Example Inputs
- **Subject Name**: Computer Science  
- **Task Description**: CS-2 Project  
- **Due Date**: September 30, 2025  
- **Priority Level**: High  

---

### Example Outputs
- **Organized Assignment List**:
  - "CS-2 Project (High Priority)"
  - Due: September 30, 2025  
  - Days Left: 5  

- **Sorted by urgency**, with closest deadlines shown first.

- **Reminder Messages**, such as:
  - "Reminder: CS-2 Project is due in 3 days."
  - "Overdue: CS-2 Project was due 2 days ago."
