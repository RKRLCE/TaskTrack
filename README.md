# TaskTrack: An Assignment Tracker App

TaskTrack is a student app that helps users keep track of school work in one place. It helps students organize tasks, check deadlines, and see which assignments need attention first.

The app lets users add tasks, choose due dates and due times, set priority levels, update task details, and move tasks between active, finished, and archived sections. It also lets users drag tasks into their own custom order if they do not want the automatic order.

---

## Overview

Students often have many assignments from different subjects. Because of that, it is easy to:

- Forget important tasks
- Submit work late
- Feel stressed because everything is mixed together
- Get confused about what should be done first

TaskTrack was made to solve this problem in a simple way. It gives students one organized place where they can manage school tasks and see what is upcoming, urgent, finished, or overdue.

---

## Current Features

### 1. Add and Manage Assignments
Users can create a task with:

- Subject name
- Task description
- Due date
- Due time
- Priority level
- Progress percentage

### 2. Edit Task Details
Users can edit a task after it is created, including:

- Subject
- Task description
- Due date
- Due time
- Priority
- Progress

### 3. Notes and Checklist
Each task can also have extra notes and a checklist. This helps students write reminders, instructions, materials to bring, or step-by-step parts of the task.

### 4. Status Tracking
Each task can be placed in different sections:

- Pending
- Completed
- Archived

This makes it easier to separate unfinished work from finished work.

### 5. Finished and Archived Task Views
The Tasks section has separate views for:

- Active tasks
- Finished tasks
- Archived tasks

Users can restore finished or archived tasks if needed.

### 6. Automatic Sorting and Custom Drag-and-Drop Order
By default, active tasks are sorted by:

1. Due date and time
2. Priority level

If the user wants a different arrangement, they can drag tasks into a custom order and save that order.

### 7. Due-Time-Aware Urgency Tracking
TaskTrack checks both the due date and due time. It can show messages like:

- Due now
- Due in 2 hours
- Due in 1 day, 3 hours
- Overdue by 45 minutes

This helps students understand how urgent a task really is.

### 8. Upcoming and Overdue Sections
The Home page shows:

- Total tasks
- Upcoming tasks
- Overdue tasks

This gives users a quick view of what needs attention.

### 9. Undo for Important Actions
TaskTrack has short undo options for actions like:

- Adding a task
- Deleting a task
- Clearing finished tasks
- Resetting custom order

This helps users fix mistakes more easily.

### 10. Theme and Safety Settings
The app includes theme choices and settings such as:

- Default
- Blue
- Light
- Pink
- Peach
- Sky

It also has delete safety settings and urgency hour settings.

### 11. Local JSON Storage
Task data and settings are saved in local JSON files. This means the app can keep data without needing an online database.

### 12. Improved User Interface
The app has a cleaner and more modern layout with:

- Bigger task cards
- Progress rings
- Clear buttons
- Search and filtering
- Help guide popup
- Finish animation
