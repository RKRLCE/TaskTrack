# Final Reflection and Evaluation

Working on **TaskTrack** was a fun and meaningful experience for both of us. Throughout the project, we learned many new skills such as coding, using front-end and back-end development, working with Flask, and managing data using JSON files. We also learned how to use IDEs like Visual Studio Code and how to properly document and manage a project through GitHub.

Aside from the technical skills, we improved our teamwork, communication, problem-solving, and patience while debugging and improving the application. We experienced challenges while implementing features and fixing issues, but these helped us better understand how real software development works.

Overall, creating TaskTrack together was both enjoyable and rewarding because we were able to turn our ideas into a working web application that can help students stay organized and manage their assignments more effectively.
